# 計画ボード（試作版）

日々の作業予定を組み立てて、生産計画の制約を自動でチェックするツールです。
Python の標準機能だけで動くので、追加でインストールするものはありません。

## 起動

`start.bat` をダブルクリックすると、ブラウザで `http://127.0.0.1:8765/` が開きます。
終了するときは、黒い画面で Ctrl+C を押します。

初めて起動したときは、親フォルダの Excel から次のデータを自動で取り込みます。

- `Book1.xls` の Sheet1 → 製品マスタ
- `作業予定表_復旧 (2).xls` の日付シート → 過去の作業予定
- 作業予定表の解凍棚の表 → 解凍kg/B

元の Excel は読むだけで、書き換えません。
最初から取り込み直したいときは `python importer.py --reset` を実行します（アプリで入力した内容は消えます）。

## 画面

| タブ | できること |
|---|---|
| 作業予定 | ライン別に製品を並べる。⋮⋮ をドラッグして順番やラインを変える。開始時刻が空欄なら、前の製品の終了時刻から自動で計算する。Ctrl+S で保存 |
| 製品マスタ | 朝一限定・特殊原料・解凍kg/B などの印を直す（変更は即保存） |
| 変更履歴 | 保存するたびに「追加・削除・バッチ変更・移動」を自動で記録する。保存のたびに改版番号（改-N）が上がる |
| 設定 | 夜勤の開始時刻、解凍庫の容量、排水の上限、祝日、閲覧用HTMLの出力先 |

「閲覧用に出力」を押すと、設定した出力先に `計画_日付.html` と `index.html` を書き出します。
出力先を共有フォルダにしておけば、現場や品管はそのファイルをブラウザで開くだけで見られます。
画面には、前処理・後処理・品管・変更履歴のタブがあります。

## 自動チェックするルール

| レベル | ルール |
|---|---|
| NG | 朝一限定／製造順番ラスト（特殊原料）／単一の重なり／機械割り（MSとキャリアを両方使う製品は、製造時間の重なりで2品まで。配合欄が空の製品は数えない）／解凍肉（曜日別の容量）／ロティールかぶり①②／排水処理（ロティール 20B・休日前 10B・夜間 10B、フジ食品 13B）／チーズ使用製品は昼勤／土曜・祝日・連休前後は包装機製品／前の製品と時刻が重なる |
| 注意 | 単一は基本朝一／火星人使用製品は昼勤／卵なしを卵ありの後に置いている／Bライン 団子→HB→団子／Dライン 三育の後のロティール（DeJong洗浄）／4ライン稼働 |
| 情報 | 余裕時間①③／切替タイミングの重なり・夜勤の切替回数／解凍kg 未設定の製品 |

自動で判定できないルール（製造可能曜日、木綿豆腐・キャベツの量、タレの配合回数など）は、画面の「人の目で確認」にチェックリストとして出します。

## 注意

- 朝一限定・特殊原料・ロティール区分などの印は、製品名や備考から**自動で推定**しています。違っていたら製品マスタで直してください。
- 解凍kg/B は、作業予定表の解凍棚の表にあった17製品だけ自動で入っています。それ以外の製品は製品マスタで入力してください。
- 夜勤の開始時刻は仮に 17:00 にしています。設定で変えられます。
- 時刻を固定している製品をドラッグで移動すると、その製品の開始時刻は自動計算に戻ります。

## ファイル構成

```
app/
  start.bat     起動用
  server.py     Webサーバー・API
  rules.py      時刻の計算と制約チェック
  importer.py   Excel からの取り込み
  export.py     閲覧用HTMLの出力
  db.py         データベースの定義
  static/       画面（HTML・CSS・JavaScript）
  data/plan.db  データ（自動で作成）
  export/       閲覧用HTMLの出力先（初期値）
```
