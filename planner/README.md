# 生産計画アプリ（Step 1：週間予定／Step 2：作業予定）

週間製造予定表を入力して配布用のExcelを発行し、そこから日ごとの作業予定（成型予定表・前処理製造予定表）を作るアプリです。
Step 3（後工程の計画）は、このアプリに順番に追加していきます。

## 起動と終了

- **起動**：`生産管理.bat` をダブルクリックします。ブラウザで画面が開きます。
- **終了**：黒い画面を閉じます。

初めて起動したときは、親フォルダの Excel から次のデータを取り込みます。

- `Book1.xls` → 製品マスタ
- `2022年10月週間予定.xls` → 今週以降の週間予定

元の Excel は読むだけで、書き換えません。
取り込みの結果は `data/import_report.txt` に出ます（cs が Excel と合わない明細、出来高/B が未設定の製品など）。

## 使い方

1. 左の「週の一覧」から週を選びます（2ヶ月先まで表示します）。
2. マスの「＋ 追加」から、製品コード（製品名でも検索できます）と B数 を入れます。cs は「B × 出来高/B」で自動計算します。
3. ⋮⋮ をドラッグすると、明細を別の日・別のラインへ移動できます。
4. 「保存」（Ctrl+S）で保存します。保存するたびに、変更内容が「変更履歴」に記録されます。
5. 配るときは「発行（Excel出力）」を押します。
   - 最初は「初版」、次からは「改-①」「改-②」…と版が上がります。
   - 前回の発行から変わった明細は赤字になります。削除した明細は、Excel の下の「変更内容」に書かれます。
   - Excel は `config.json` の `output_dir` に `週間予定_2026年11月第3週.xlsx` という名前で出力します。同じ週を発行し直すと、ファイルは上書きされます。

## タレ欄（内添タレ）

- 表の右端の「タレ」列に、日ごとのタレの品名と kg を出します。
- **自動**：ラインに入れた製品に「内添タレ kg/B」（製品マスタ）があれば、`B数 × kg/B` を自動で出します。B数や製品を変えると追従します。
- **手**：自動の kg を直すと、その行は手入力になり、以後は自動計算されません。✕ で消すと自動に戻ります。
- 4号機の製品化の日など、ラインに製品が無い日のタレは「＋ 追加」で入れます（品名だけでも可）。
- 内添タレ kg/B は、取り込み時に過去の週間予定（2025年4月以降）の実績から、いちばん多い値を入れています。
- 発行した Excel では、Dラインの右に「タレ（品名・数量）」が出ます。変更は赤字になります。

## 別添タレ

- 表の右端の「別添タレ」列に、作り置きする小袋のタレを入れます。
- 半製品コード（89xxx。候補が出ます）と kg を入れると、使う製品（→製品名）と袋数が出ます。
- 袋数は `kg × 袋/kg` で自動計算します（灰色の斜体）。手で直すと「袋（手）」になり、空にすると自動に戻ります。
- 半製品の「別添→製品」「袋/kg」は製品マスタで直せます。取り込み時に、過去の実績からいちばん多い値を入れています。
- 発行した Excel では、タレの右に「別添タレ（品名→製品・タレkg・包装機の袋数）」が出ます。
- 在庫の管理はまだしていません。

## 作業予定（Step 2：前工程）

「作業予定」タブで、日ごとにライン別の製造順と時刻を決めて、成型予定表と前処理製造予定表を発行します。

1. 日付（◀ ▶ か、上の日付ボタン）を選びます。
2. まだ保存していない日は、週間予定から自動で作った**案**が出ます。
   - 週間予定のマスの順番で並べます。
   - 夜の休止（初期値 20:00）をまたぐ製品は、0.5B 単位で休止の前後に分けて、後ろの行の切替を 120分にします。
3. 順番・切替・開始時刻を直して「保存」（Ctrl+S）します。
   - **開始** ＝ 前の製品の終了を5分単位に切り上げた時刻 ＋ 切替（分）。朝一は各ラインの開始時刻。
   - **終了** ＝ 開始 ＋ B数 × 分/B（分/B は製品マスタの値）。
   - 開始時刻に時刻を入れると、その時刻に**固定**します（太字の枠）。空にすると自動に戻ります（灰色の斜体）。
   - ⋮⋮ をドラッグすると順番を変えられます（同じラインの中だけ）。
   - 「分ける」で1つの行を2つに分けます（休止をはさむときなど。後ろの行の切替は 120分になります）。✕ で消すと、同じ製品の行があればそちらに B数を足します。
4. 配るときは「前処理製造予定表を発行」「成型予定表を発行」を押します。2つは別々に改版します（前処理製造予定表は4日前に配るため）。
   - 成型予定表：B数か開始時刻が変わった行を赤字にします。
   - 前処理製造予定表：製品ごとの B数の合計が変わった行を赤字にします（分けた行は1行にまとめます）。投入袋数・前処理再生の欄は手書き用に空けてあります。
   - Excel は `config.json` の `day_output_dir` に `成型予定表_2026年11月4日.xlsx`、`前処理製造予定表_2026年11月4日.xlsx` という名前で出力します。

### 週間予定を変えたとき

- 作業予定を保存したあとで週間予定の B数・製品を変えると、作業予定の画面に「週間予定と B数が合いません」と出ます。
- 「週間予定に合わせる」を押すと、消えた製品を消し、B数が変わった製品は最後の行で増減し、増えた製品はラインの最後に足します（順番・切替・固定した時刻はできるだけ残します）。
- 「週間予定から作り直す」は、今の作業予定を捨てて案を作り直します。
- ラインを変えたいとき・B数の合計を変えたいときは、週間予定のほうで変えてください（作業予定 → 週間予定には反映しません）。

### 画面の項目と、印刷する項目

- 画面には、作業予定表・作業日報（前）・前処理製造予定表にある項目をすべて出します（27項目）。
  コードNO・製品名・バッチ・ショット・時間/B・配合・切替・開始・終了・予定出来高（cs）・モールド板・プレート・成型g・食肉区分・その他・油揚・色・再生・小麦・卵・乳・注意事項・洗浄事項・後処理 箱詰め規格・包装形態・後処理番号・金検
- 横にスクロールしても、コードNO と製品名は左に残ります。4ラインの表は一緒にスクロールします。
- 「印刷する項目…」で、成型予定表に印刷する項目を選びます。チェックした項目だけを、画面と同じ並びで印刷します。
  - 初期値は今の作業予定表と同じ17項目です（「初期値に戻す」で戻せます）。
  - 選んだ内容はみんなで共通です（保存すると、次に発行する成型予定表から使います）。
  - 画面の見出しが灰色の点線の項目は、今は印刷しない項目です。
  - 項目だけを変えて印刷し直したいときは、もう一度「成型予定表を発行」を押します。中身が前回の発行と同じなら、版を上げずに出力し直します。
- 前処理製造予定表は、今の様式のまま（項目は選べません）。

### 製品の情報

- ショット・配合・モールド板・プレート・成型g・食肉区分・その他・油揚・色・再生・小麦・卵・乳・注意事項・洗浄事項・箱詰め規格・後処理番号・金検・分/B は、Book1 から取り込んでいます。
- 分/B・ショット・配合・モールド板は製品マスタの画面で直せます。
- Book1 を直したときは `python src\importer.py --forming` を実行すると、Book1 の値で入れ直します（製品マスタで直した分/B なども Book1 の値に戻ります）。
- 分/B が未設定の製品は、終了時刻が計算できないので画面に警告が出ます。

## 何人かで使うとき（編集の鍵）

- 編集できるのは、先に起動した1人だけです。後から起動した人は「閲覧のみ」になり、画面の上に誰が編集中かが出ます。
- 編集中の人が画面を閉じれば、次に起動した人が編集できます。
- PCが固まるなどして鍵が残った場合でも、3分たてば次の人が引き継げます。急ぐときは「編集を引き継ぐ」ボタンを押します（相手は保存できなくなります）。
- 編集モードで起動するたびに、データを `data/backup/` に自動でコピーします（最新30個を残します）。

## 共有フォルダへの置き方

1. この `planner` フォルダを、フォルダごと共有フォルダにコピーします。
2. `config.json` を開いて、`output_dir` を配布用 Excel を置く共有フォルダに書き換えます。
   例：`"output_dir": "\\\\server\\生産管理\\週間予定"`（`\` は2つずつ書きます）
3. 使う人のPCで Python が動くか確かめます。コマンドプロンプトで `python --version` と打ち、`Python 3.10` 以上と出ればそのまま使えます。
   動かないPCがある場合は、インストール不要の Python（embeddable 版）を `planner\python\` に置けば、`生産管理.bat` が自動でそれを使います。
   置くときは `python\python312._pth` に `..\src` の1行を書き足します（無いとプログラムを見つけられず起動しません）。
   共有フォルダ（`\\SV-NAR\KANSAIBF_DATA\生産予定\製造計画アプリ`）には Python 3.12.10 を置いてあるので、どのPCでもインストール不要です。

共有フォルダはファイルを開くのが遅いため、`生産管理.bat` は起動のたびにプログラム（`src`・`static`・`lib`・`python`）を各PCの `%LOCALAPPDATA%\SeizoKeikakuApp` にコピーして（変わったファイルだけ）、そこから動かします。データ（`data`）・設定（`config.json`）・出力は共有フォルダのものを使います。初回の起動は20〜30秒、2回目からは数秒かかります。

プログラムを直したときは、共有フォルダの `src`・`static`・`生産管理.bat` だけを上書きします。`data` と `config.json` は上書きしないでください（入力したデータと設定が消えます）。

## 設定（config.json）

| 項目 | 内容 |
|---|---|
| output_dir | 配布用 Excel（週間予定）の出力先 |
| day_output_dir | 成型予定表・前処理製造予定表の出力先 |
| line_start | 作業予定の各ラインの朝一の開始時刻（例：`{"A": "7:30", "B": "7:20", "C": "7:35", "D": "7:20"}`） |
| gap_min | 作業予定の切替の初期値（分）。初期値 30 |
| night_break / night_break_min | 夜の休止の時刻と長さ（分）。初期値 20:00・120分 |
| distribution | Excel の一番上に印刷する配布先 |
| source_master_xls / source_weekly_xls | 最初の取り込みに使う Excel |
| port | 画面のアドレスの番号（ふつうは変えなくてよい） |
| backup_keep | 残すバックアップの数 |

## 取り込み直したいとき

`python src\importer.py --reset` を実行すると、データを消して Excel から取り込み直します。
**アプリで入力・発行した内容は全部消えます。** 並行運用を始めたら使わないでください。

## Step 1 でまだやらないこと

- 制約の自動チェック（後の Step で追加します）
- 特注依頼・見込み生産品の管理
- 昼勤・夜勤、ムルチの列、注意書き
- 別添タレの在庫

## Step 2 でまだやらないこと

- 作業日報（前）（予定出来高・実績の欄がある日報）
- 作業予定表の右側の表（解凍棚の使用量・原料肉・タレ量・機械割確認）
- 製品の組み合わせごとの切替時間（今は1行ずつ手で入れる。初期値は30分）
- 制約の自動チェック

## ファイル構成

```
planner/
  生産管理.bat          起動
  config.json        設定（初回起動時に作成）
  src/
    server.py        画面とのやり取り・保存・発行
    importer.py      Excel からの取り込み
    excel_out.py     配布用 Excel（週間予定）の作成
    day.py           作業予定（案の作成・時刻の計算・週間予定との突き合わせ）
    day_out.py       成型予定表・前処理製造予定表の Excel の作成
    lock.py          編集の鍵・バックアップ
    db.py            データベースの定義
    config.py        設定の読み込み
  static/            画面（HTML・CSS・JavaScript）
  lib/               同梱ライブラリ（openpyxl・xlrd。ライセンスは lib/licenses）
  data/              データ（plan.db）・バックアップ・取り込みレポート
  output/            配布用 Excel・成型予定表・前処理製造予定表（初期の出力先）
```
